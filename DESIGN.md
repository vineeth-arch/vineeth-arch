# Profile Design

## Surface and scene

A recruiter scans the profile in a browser, in GitHub's chosen light or dark theme. A self-contained violet masthead carries the visual identity; native text follows the viewer's theme and remains readable in both.

## Direction

Playful creative lab: cut-paper experiments and screenprinted studio posters, with the existing avatar's violet and mint. A full palette is appropriate for the masthead; surrounding content uses GitHub's native typography and spacing. This is a portfolio, not a dashboard.

## Color roles

- Violet: primary identity field, approximately OKLCH(0.35 0.20 290).
- Mint: signature accent, approximately OKLCH(0.84 0.19 163).
- Marigold: playful secondary paper shape, approximately OKLCH(0.86 0.15 90).
- Vermilion and cobalt: small supporting accents.
- Ivory: high-contrast masthead lettering; native text inherits GitHub's theme.

## Typography

Banner lettering has a bold, humanist, cut-paper-poster voice. README text uses GitHub's native font; custom CSS and font loading are not supported. Avoid imitating a selectable web font through images for body copy. All important banner information has a text counterpart.

## Composition

Full-width 3:1 masthead; short introduction and native anchor navigation; a public TV experiment with its real, clearly labeled simulation preview; selected private projects explained in readable native text; a compact skills line; and the full portfolio inside nine category disclosures.

## Assets and dependencies

Store the generated static masthead in this repository. Use an explicitly versioned public V/HOME screenshot after inspecting it. No external statistics services, tracking pixels, scripts, badges or animation dependencies.

The copied V/HOME simulation screenshot comes from `docs/screenshots/after-launcher-curated.png` in `vineeth-arch/v-home` at commit `b29c08dc71725f60f10095e12ca1d9d46120e721`. The profile labels it as a browser simulation. The masthead was generated for this profile using the image generation tool.

## Content rules

Preserve all 45 six-line summaries. Public repository links remain limited to the approved public projects. Private featured projects link to their expanded catalogue sections. Describe prototype limits honestly without turning the introduction into an audit report.
