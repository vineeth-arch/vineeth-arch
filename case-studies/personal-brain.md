# Personal Brain OS

**KNOWLEDGE / SYSTEMS** · Private source · public project narrative

A self-hosted cockpit connecting everyday capture with a Markdown knowledge base.

## The question

Notes, links, voice and photos often live in separate places. Capturing them is easy; making them useful later is harder.

## The system

Capture pipelines turn incoming material into structured Markdown for an Obsidian vault. A cockpit brings together daily work and human-reviewed relationship proposals.

## Why it helps

A consistent capture-to-knowledge workflow reduces fragmentation and makes personal context easier to revisit.

## The craft

Python / FastAPI / React / SQLite

## Scope and evidence

A self-hosted personal system. Relationship changes remain human-reviewed; private notes and personal records are not published here.

This narrative is based on repository documentation reviewed on 27 October 2026. It describes the system and its intended value; it is not a new runtime test or a claim of measured business outcomes.
