# V / The studio identity

**BRAND / VISUAL SYSTEM** · Public source

A personal identity joining brand strategy, design, consulting and software products.

## The question

An interdisciplinary practice can look fragmented when design work and technical work are presented as unrelated identities.

## The system

Bricolage Grotesque display type and Hanken Grotesk supporting text connect the portfolio. Indigo and teal define the public artwork in every browser theme; bone and pink serve the print profiles. Tonal blocks, dot grids and circular arrows follow the Design Innsaeit visual system.

## Why it helps

Visitors can understand the breadth of the practice while following a consistent visual and narrative structure.

## The craft

Brand architecture / art direction / SVG / editorial systems

## Scope and evidence

This profile is the live identity application. Graphics are original vector studies; the V/HOME preview is labeled separately as an actual browser simulation.

This narrative is based on repository documentation reviewed on 27 October 2026. It describes the system and its intended value; it is not a new runtime test or a claim of measured business outcomes.
